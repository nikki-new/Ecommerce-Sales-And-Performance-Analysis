# Ecommerce-Sales-And-Performance-Analysis
End-to-end E-Commerce analytics evaluating sales, profit margins, order statuses, shipping efficiency, and customer demographics using Python &amp; Power BI.

## 🛠 Tech Stack & Tools
* **Data Processing & Analysis:** Python (Pandas, NumPy)
* **Data Visualization:** Matplotlib, Seaborn, Power BI
* **Reporting & Profiling:** Automated Profiling (`ydata-profiling`)
* **Dataset:** Excel (`Ecommerce project analysis new.xlsx`)

---

##  Key Business Highlights & Analysis

### 1. Sales & Financial Metrics
* **Key KPIs:** Evaluated Total Sales, Total Profit, Average Order Value (AOV), and Profit Margin % across transactions.
* **Discount Impact:** Analyzed profit margin fluctuations relative to discount tiers to assess discounting efficiency.

### 2. Operations & Delivery Performance
* **Order Fulfillments:** Tracked status proportions for Delivered, Cancelled, and Returned orders.
* **Shipping Modes:** Computed average delivery duration and total sales/profit generated per shipping method.

### 3. Customer & Demographics Breakdown
* **Customer Segmentation:** Analyzed sales volume and order frequency across age brackets (`18-24`, `25-34`, `35-45`, `46-55`, `56+`) and gender profiles.
* **Regional & Payment Dynamics:** Identified top-performing geographic regions and customer payment mode preferences.
